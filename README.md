# CalculadoraWeb 🧮

Una calculadora web sencilla e intuitiva con **diseño neón e historial de operaciones**.

## 🚀 Características
- **Diseño Neón:** Interfaz moderna y atractiva.
- **Historial:** Guarda el registro de tus operaciones recientes.
- **Responsiva:** Se adapta tanto a pantallas de computadora como a dispositivos móviles.

## 🛠️ Tecnologías utilizadas
- **HTML5**
- **CSS3**
- **JavaScript**
